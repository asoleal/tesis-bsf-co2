# Modelo de CO2 en bioconversión con Hermetia illucens

Repositorio limpio para reconstruir el modelo, verificar los datos, calibrarlo y validarlo con mediciones propias y literatura externa.

## Estructura

- `datos/crudos`: archivos originales, sin modificar.
- `datos/procesados`: tablas trazables derivadas de los crudos.
- `modelo`: definición matemática y código del modelo.
- `scripts`: reproducción de cálculos, calibración y validación.
- `resultados`: salidas numéricas y tablas.
- `figuras`: figuras generadas.
- `secciones`: texto LaTeX del artículo.
- `bibliografia`: bibliografía BibTeX.

## Regla de trazabilidad

Todo resultado debe indicar datos de entrada, script, fecha y versión del modelo utilizada.
